# QR-TT 二维码模拟测试工具

Android 原生应用（Java，最低 Android 5.0 / API 21），用于按设定节律批量模拟生成二维码。

仓库：<https://github.com/closerose-Tech/qr-tt>

## 数据规则

默认基础数据模板：

```
HTTPS://Y2WM.CN/99.1000.1/AC2007999003QG4D59CTWOESG990C0001
```

模板共 59 个字符，运行时把**最后 24 位**替换为 `0-9A-Z` 随机串（例如模板前缀为
`HTTPS://Y2WM.CN/99.1000.1/AC2007999`）。应用内部维护已生成尾码集合，保证每次生成的尾码都不重复。
模板内容与随机位数均可在界面「数据规则」中修改。

## 已实现功能

| 需求 | 实现位置 |
| --- | --- |
| QR 码、纠错级别 L/M/Q/H | 外观 → 纠错级别（ZXing 编码） |
| 静区大小可调 | 外观 → 静区(模块数)，默认 4 个模块，可设 0~20 |
| 显示尺寸可调 | 外观 → 显示尺寸(dp)，默认 30dp，可设 8~600dp |
| 本体色 / 背景色可设定 | 外观 → 本体颜色 / 背景颜色（取色器 + 预设色板 + #RRGGBB 输入） |
| 环境色固定 / 随数据随机 | 外观 → 环境颜色、环境色变化（固定颜色 / 随数据随机） |
| 方向设定 | 外观 → 二维码方向：0° / 90° / 180° / 270° |
| 镜像二维码 | 外观 → 镜像显示：正常 / 镜像码（水平翻转） |
| 滑动方式 | 外观 → 滑动方式：静止 / 从左向右 / 从右向左；二维码从一侧滑入、停留后从另一侧滑出，滑入/滑出时长可调 |
| 数据保持时间、变化间隔 | 变化时序，1ms ~ 10s，单位可选毫秒/秒 |
| 变化次数限制（默认 100） | 变化次数，0 表示不限 |
| 按时间停止 | 限时(分钟)，支持小数，0 表示不限 |
| 启动 / 暂停 / 停止 / 复位 | 界面按钮；复位将计数清零并清空已生成尾码，可从头开始 |
| 同屏 1~6 个二维码 | 二维码数量；数据可选「各码不同」或「全部相同」 |
| 常亮不锁屏 | 屏幕常亮开关 + `FLAG_KEEP_SCREEN_ON` + WakeLock |
| 安装包 | `app/build/outputs/apk/release/app-release.apk` |

配置会自动保存到 SharedPreferences，下次启动沿用上次设置。

## 构建

环境：JDK 17、Android SDK Platform 33、Build-Tools 33.0.2、Gradle 7.6、AGP 7.4.2。

```bash
# local.properties 中指定本机 SDK 路径
sdk.dir=你的SDK路径

gradle assembleRelease
```

签名密钥库为 `app/release.jks`（测试用，口令 `qrtt2026`）。

## 时序说明

一个变化周期为：`生成数据并显示二维码 → 保持 holdMs → 清空画面 → 间隔 gapMs → 下一轮`。
滑动模式下，保持时间内依次执行「从一侧滑入 → 停留 → 从另一侧滑出」；滑入/滑出各占 `min(设定时长, holdMs/2)`，剩余时间用于停留。
次数或时长任一条件先到达即自动停止；停止后保留最后一屏二维码，点击「启动」重新开始。
极小的毫秒值受屏幕刷新率限制，实际渲染间隔以系统帧率为准。
